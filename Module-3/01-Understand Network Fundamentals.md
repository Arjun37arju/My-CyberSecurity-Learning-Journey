## a. What is Networking

### Content

**Networking** is the process of **connecting computers and devices so they can communicate and share data and resources**.

A network can connect:

* Computers
* Phones
* Servers
* Printers
* Routers
* Other network devices

```text
Computer
    ↓
  Network
    ↓
Computer
    ↓
Server
```

Example:

> Your laptop connects to Wi-Fi and communicates with other devices and Internet services.

**Easy idea:**

> **Networking = Connecting devices so they can communicate and share resources.**

## b. Network Communication

### Content

**Network communication** is the process of **sending and receiving data between devices over a network**.

```text
Device A
   ↓
Data
   ↓
Network
   ↓
Device B
```

For communication to happen, devices use rules called **protocols**.

Examples include:

* HTTP
* HTTPS
* DNS
* TCP
* UDP
* SSH

Example:

> When you open a website, your device communicates with a web server to request and receive information.

**Easy idea:**

> **Network Communication = Devices sending and receiving data.**

## c. Network Architecture

### Content

**Network architecture** describes **how a network is designed and how its devices and services are organized**.

A simple network may look like:

```text
Internet
    ↓
 Router
    ↓
 Switch
 ┌──┼──┐
 ↓  ↓  ↓
PC PC Printer
```

Common concepts include:

* Client
* Server
* Network devices
* Communication paths
* Network services

For example:

> A client requests a service, and a server provides that service.

```text
Client
  ↓
Request
  ↓
Server
  ↓
Response
  ↓
Client
```

## d. Network Components

### Content

**Network components** are the hardware and software used to build and operate a network.

Common components include:

### Router

Connects different networks and forwards traffic between them.

```text
Network A
    ↓
 Router
    ↓
Network B
```

### Switch

Connects devices within a local network.

```text
PC ──┐
PC ──┼── Switch
PC ──┘
```

### Access Point

Allows wireless devices to connect to a network.

```text
Phone
  ↓
Wi-Fi
  ↓
Access Point
```

### Network Interface Card (NIC)

Allows a device to connect to a network.

### Modem

Provides communication between a local network and an Internet service connection, depending on the type of Internet service.

**Easy idea:**

> **Network Components = Devices that help build, connect, and operate a network.**

## e. Data Transmission

### Content

**Data transmission** is the process of **sending data from one device to another through a communication medium**.

Data can travel through:

* Ethernet cables
* Fiber-optic cables
* Wi-Fi
* Other wireless technologies

```text
Sender
   ↓
Data
   ↓
Transmission Medium
   ↓
Receiver
```

For example:

> When you send a file from your laptop to another computer, the data travels through a network medium between the devices.

Data can be transmitted in different ways, including:

* Wired transmission
* Wireless transmission

**Easy idea:**

> **Data Transmission = Moving data from one device to another.**
