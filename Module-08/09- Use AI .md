## Use AI

Use AI as a helper throughout your development and security work.

You can use AI for:

* Code reviews
* Security reviews
* Architecture discussions
* Secure coding suggestions
* Understanding errors
* Finding possible security weaknesses
* Improving your implementation

---

## Validate AI Output

Don't blindly trust AI-generated suggestions.

Always:

* Review the recommendations
* Check whether they are actually correct
* Test the suggested changes
* Verify the security and quality of the implementation

> **Use AI as a helper, but always verify its output yourself.**
