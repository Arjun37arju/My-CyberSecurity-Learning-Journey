# Python Port Scanner

## Description
A simple Python tool that checks a range of TCP ports on a target host and displays open ports.

## Concepts Used
- Python socket library
- TCP connections
- Port scanning
- Exception handling

## Usage
1. Install Python.
2. Save the code as `port_scanner.py`.
3. Run the program:

```bash
python port_scanner.py
```

## Example
The program scans ports 1–100 on `example.com` and displays the results.

## Note
Use port-scanning tools only on systems you own or have permission to test.
