## 1. What is Cryptography

**Cryptography** is a method of protecting data using mathematical techniques to prevent unauthorized access or modification.

### Why is cryptography used?

* Protect data from unauthorized access
* Protect data from theft
* Prevent unauthorized modification
* Secure communication

---

## 2. Security Goals

The main security goals are commonly represented as **CIA**:

* **C — Confidentiality**
* **I — Integrity**
* **A — Authentication**

---

## 3. Confidentiality

**Confidentiality** means protecting data from unauthorized access or disclosure.

### Example

Encryption can protect a message so that only the intended receiver can read it.

---

## 4. Integrity

**Integrity** means ensuring that data is not changed, modified, or tampered with without authorization.

### Example

If a file contains `₹10,000`, an attacker should not be able to secretly change it to `₹1,000`.

---

## 5. Authentication

**Authentication** is the process of verifying the identity of a person, device, or system.

### Example

A username and password can be used to verify a user's identity.
