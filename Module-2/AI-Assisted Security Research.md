# AI-Assisted Security Research

AI can help cybersecurity researchers **analyze threats, understand malware, summarize security information, research vulnerabilities, and assess risks**.

However, AI can produce incorrect or incomplete information. Therefore, cybersecurity researchers must **verify AI-generated results before trusting or using them**.

# a. Use AI For

AI can be used as a **research assistant** to help understand and organize cybersecurity information.

The important idea is:

```text id="f4r8k2"
Cybersecurity Topic
       ↓
Ask AI
       ↓
AI Analysis
       ↓
Research Sources
       ↓
Verify Information
       ↓
Final Understanding
```

> **AI should assist your research, not replace your research.**

---

## i. Threat Analysis

### Content

**Threat analysis** is the process of understanding a cybersecurity threat, how it works, what it targets, and what impact it can have.

AI can help you:

* Understand a threat
* Identify attack techniques
* Summarize threat reports
* Identify potential targets
* Organize threat information
* Identify possible defensive measures

### Practical Task

Choose a **publicly documented cybersecurity threat**.

Ask AI questions such as:

> "Explain this threat in simple terms."

> "What systems does this threat target?"

> "What attack techniques are associated with it?"

> "What is the potential impact?"

Then research the same threat using reliable security sources.

Compare the AI response with your sources.

### Deliverable

Create a **Threat Analysis Report**:

```text id="h3q7v9"
Threat:
Threat Type:
Target:
Attack Techniques:
Impact:
Defensive Measures:

AI Findings:
Verified Findings:
Sources:
```

**Goal:**

> Learn how AI can assist with threat analysis while developing your own research and verification skills.

## ii. Malware Research

### Content

AI can help researchers understand malware by explaining:

* Malware type
* General behavior
* Infection methods
* Targets
* Impact
* Detection methods
* Defensive measures

AI should be used for **analysis and learning**, not for creating or improving malware.

```text id="m8v2c5"
Malware
   ↓
Research
   ↓
Ask AI
   ↓
Understand Behavior
   ↓
Verify With Sources
```

### Practical Task

Choose a **known malware family** and research it using AI.

Ask AI to explain:

* What type of malware it is
* How it reaches victims
* What it does
* What systems it targets
* Its impact
* How defenders can detect or prevent it

Then compare the AI's information with reliable malware research reports.

**Goal:**

> Learn how AI can help understand malware while validating technical information against trusted research.

## iii. Security News Summarization

### Content

Cybersecurity news and reports can be long and contain a large amount of technical information.

AI can help summarize them into important points.

```text id="s6n4p8"
Security Article / Report
          ↓
          AI
          ↓
Important Information
          ↓
Verify With Original Source
```

AI can help identify:

* What happened
* Who was affected
* What type of incident occurred
* Impact
* Response
* Important security lessons

### Practical Task

Choose a **recent cybersecurity news article or security report**.

Give the information to an AI tool and ask it to summarize:

* Main incident
* Target

* Impact

## iv. CVE Analysis

### Content

AI can help explain and organize information about **CVE (Common Vulnerabilities and Exposures)** records.

You can ask AI to help explain:

* What the vulnerability is
* Affected software
* Affected versions
* Potential impact
* Severity
* General mitigation
* Technical terminology

```text id="cve7m2"
CVE
 ↓
AI Explanation
 ↓
Understand Vulnerability
 ↓
Check Official Information
 ↓
Verified Analysis
```

### Practical Task

Choose **3 publicly documented CVEs**.

For each CVE:

1. Ask AI to explain it.
2. Record the AI's findings.
3. Check the official CVE/vendor information.
4. Compare the information.
5. Identify any differences or missing details.

### Deliverable

Create:

| CVE | AI Explanation | Official Information | Differences |
| --- | -------------- | -------------------- | ----------- |
|     |                |                      |             |
|     |                |                      |             |
|     |                |                      |             |

**Goal:**

> Learn how to use AI to understand CVEs while verifying important technical details from authoritative sources.

 ↓

# b. Validate Outputs

AI-generated cybersecurity information must be **checked before it is trusted**.

A useful workflow is:

```text id="v8c4m6"
AI Output
    ↓
Check Claims
    ↓
Find Reliable Sources
    ↓
Compare Information
    ↓
Confirm Technical Details
    ↓
Correct Errors
    ↓
Verified Findings
```

---

## i. Verify Findings

### Content

AI may provide information that sounds correct but is actually:

* Incorrect
* Outdated
* Incomplete
* Misleading
* Unsupported

Therefore, important findings should be checked against reliable sources.

### Practical Task

Take one of your previous AI research tasks.

Select **5 claims made by AI**.

For each claim:

1. Find a reliable source.
2. Check whether the claim is correct.
3. Mark it as:

   * Correct
   * Partially correct
   * Incorrect
4. Explain your conclusion.

### Deliverable

| AI Claim | Source | Verification | Result              |
| -------- | ------ | ------------ | ------------------- |
|          |        |              | Correct / Incorrect |
|          |        |              | Correct / Incorrect |
|          |        |              | Correct / Incorrect |
|          |        |              | Correct / Incorrect |
|          |        |              | Correct / Incorrect |

**Goal:**

> Develop the habit of verifying AI-generated cybersecurity information.

## ii. Confirm Technical Details

### Content

Cybersecurity contains many technical details that must be accurate.

Examples include:

* CVE numbers
* Software versions
* Protocols
* Vulnerability descriptions
* Attack techniques
* Security controls
* Commands or configurations

AI can sometimes generate **incorrect technical details or hallucinate information**.

### Practical Task

Choose one technical cybersecurity topic and ask AI to explain it.

Identify at least **5 technical claims** from the response.

Verify each claim using reliable technical documentation.

### Deliverable

Create:

| Technical Detail | AI Output | Verified Information | Correct? |
| ---------------- | --------- | -------------------- | -------- |
|                  |           |                      |          |
|                  |           |                      |          |
|                  |           |                      |          |
|                  |           |                      |          |
|                  |           |                      |          |

**Goal:**

> Learn to check technical accuracy instead of assuming that an AI-generated answer is correct.

## iii. Review Threat Information

### Content

Threat information can change over time.

AI may provide:

* Old information
* Incorrect threat details
* Incorrect attribution
* Missing developments
* Unsupported claims

Therefore, threat information should be compared with **current and reliable security sources**.

### Practical Task

Choose a publicly documented threat or threat actor.

Ask AI to provide an overview.

Then compare the response with information from multiple reliable sources.

Check:

* Threat identity
* Target
* Attack techniques
* Malware or tools
* Timeline
* Impact
* Current information

### Deliverable

Create a **Threat Information Verification Report**:

```text id="j7m3q9"
Threat:

AI Findings:
    
Source 1:
    
Source 2:
    
Source 3:

Verified Information:

Incorrect / Missing Information:

Final Conclusion:
```

**Goal:**

> Learn how to validate AI-generated threat information using multiple reliable sources.
