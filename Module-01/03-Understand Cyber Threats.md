# Understand Cyber Threats

A **cyber threat** is a potential danger that can cause harm to computers, networks, applications, devices, or data.

---

## a. Threats

A **threat** is anything that has the **potential to cause harm** to a system, network, application, or data.

Examples:

* Hackers
* Malware
* Phishing
* Ransomware
* Insider threats
* DDoS attacks

```text id="m4t2du"
Threat
  ↓
Potential Harm
  ↓
System / Data
```

Example:

> An attacker attempting to steal company data is a cyber threat.

**Easy idea:**

> **Threat = Something that can cause harm.**

---

## b. Vulnerabilities

A **vulnerability** is a **weakness or security flaw** in a system, application, network, or device that could be exploited.

Examples:

* Weak passwords
* Outdated software
* Misconfigured systems
* Unpatched vulnerabilities
* Insecure applications

```text id="0j7c5b"
System
   ↓
Weakness
   ↓
Vulnerability
```

Example:

> An old version of software contains a known security vulnerability.

**Easy idea:**

> **Vulnerability = A weakness that can be exploited.**

---

## c. Risks

A **risk** is the possibility of **harm or loss when a threat can take advantage of a vulnerability**.

A simple way to understand it is:

```text id="p8l2z6"
Threat
  +
Vulnerability
  ↓
Risk
  ↓
Possible Damage
```

Example:

> A company has an unpatched server. An attacker could exploit the vulnerability and steal data. This creates a security risk.

Risk can involve:

* Data loss
* Financial loss
* Service disruption
* Privacy loss
* Reputation damage

**Easy idea:**

> **Risk = Possible harm caused when a threat exploits a vulnerability.**

---

## d. Exploits

An **exploit** is a **technique, code, or method used to take advantage of a vulnerability**.

```text id="d5u5ha"
Vulnerability
      ↓
    Exploit
      ↓
Unauthorized Action
```

Example:

> An attacker uses a specially crafted input to exploit a vulnerability in a vulnerable application.

An exploit does not always mean that an attacker has successfully compromised the entire system; it refers to the method used to take advantage of the weakness.

**Easy idea:**

> **Exploit = Method used to take advantage of a vulnerability.**

---

## e. Attack Vectors

An **attack vector** is the **path or method an attacker uses to reach and attack a target**.

Common attack vectors include:

* Phishing emails
* Malicious websites
* Weak passwords
* Vulnerable software
* Infected files
* Compromised accounts
* Removable devices

```text id="q6m2l4"
Attacker
   ↓
Attack Vector
   ↓
Target
   ↓
System / Data
```

Example:

> An attacker sends a phishing email containing a malicious link. The phishing email is the attack vector used to target the victim.

**Easy idea:**

> **Attack Vector = The path or method used to reach a target.**

# How They Connect

These five concepts are closely related.

```text id="qz5j4k"
Threat
  ↓
Finds a Vulnerability
  ↓
Uses an Exploit
  ↓
Through an Attack Vector
  ↓
Creates Risk
  ↓
Possible Damage
```

### Simple Example

```text id="x4qv7r"
Attacker
   ↓
Phishing Email
   ↓
Attack Vector
   ↓
Weak Application
   ↓
Vulnerability
   ↓
Exploit
   ↓
Unauthorized Access
   ↓
Risk
```

# Quick Revision

| Concept           | Simple Meaning                                   |
| ----------------- | ------------------------------------------------ |
| **Threat**        | Something that can cause harm                    |
| **Vulnerability** | A weakness that can be exploited                 |
| **Risk**          | Possible harm or loss                            |
| **Exploit**       | Method used to take advantage of a vulnerability |
| **Attack Vector** | Path or method used to reach a target            |

### Easy Way to Remember

```text id="j2z7xk"
Threat       → Who/What can cause harm?
Vulnerability → What is the weakness?
Exploit      → How is the weakness used?
Attack Vector → How does the attacker reach the target?
Risk         → What could happen?
```

> **Threat + Vulnerability + Exploit + Attack Vector → Risk of Damage**
