# Apply Through Hands-on Tasks

Hands-on practice helps you apply cybersecurity concepts in a **realistic and controlled environment** instead of only learning theory.

Complete the following tasks to practice your cybersecurity knowledge.

---

## a. Build Personal Cybersecurity Lab

Create a **safe and isolated cybersecurity lab** where you can practice security concepts without affecting real systems.

### Task

Set up a basic lab using virtualization software such as VMware, VirtualBox, or another suitable platform.

Your lab can include:

```text
Physical Computer
       ↓
Virtualization
       ↓
 ┌─────┴─────┐
 ↓           ↓
Security VM  Test VM
```

### Steps

1. Install virtualization software.
2. Create a virtual machine.
3. Install a suitable operating system.
4. Configure the virtual network safely.
5. Create an isolated testing environment.
6. Take a snapshot of the VM.
7. Document your lab setup.

### Document

Include:

* Virtualization software used
* Virtual machines created
* Operating systems used
* Network configuration
* Isolation method
* Snapshot information
* Purpose of the lab

**Goal:**

> Build a controlled environment where you can safely practice cybersecurity.

---

## b. Analyze Recent Cyber Incidents

Choose a **recent publicly reported cyber incident** and research what happened.

### Task

Find a real cyber incident from a reliable source and investigate it.

Research:

* What happened?
* Who was affected?
* What type of attack was involved?
* What systems or data were affected?
* What was the impact?
* How was the incident discovered?
* How did the organization respond?
* What security lessons can be learned?

### Workflow

```text
Choose Incident
      ↓
Collect Sources
      ↓
Understand What Happened
      ↓
Identify Attack Type
      ↓
Analyze Impact
      ↓
Study Response
      ↓
Write Findings
```

### Document

Create a short incident analysis containing:

```text
Incident Name:
Date:
Organization:
Attack Type:
Target:
Impact:
Response:
Security Lessons:
Sources:
```

**Goal:**

> Learn how real cyber incidents happen and how organizations respond to them.

## c. Research Common Attack Types

For each attack, research:

* What it is

## d. Create Threat Landscape Report

Create a **threat landscape report** describing the major cybersecurity threats currently affecting organizations or a specific industry.

### Task

Choose a focus area.

Examples:

* General cybersecurity
* Healthcare
* Banking
* Education
* E-commerce
* Small businesses

Research:

* Common threats
* Common attack methods
* Major threat actors
* Vulnerabilities
* Recent incidents
* Potential impact
* Security measures

### Report Structure

```text
1. Introduction
2. Current Threats
3. Common Attack Methods
4. Threat Actors
5. Vulnerabilities
6. Recent Incidents
7. Potential Impact
8. Security Measures
9. Conclusion
10. Sources
```

### Workflow

```text
Choose Industry
      ↓
Research Threats
      ↓
Collect Reliable Sources
      ↓
Analyze Information
      ↓
Identify Major Risks
      ↓
Create Report
```

**Goal:**

> Learn how to research and present the current cybersecurity threat landscape.
