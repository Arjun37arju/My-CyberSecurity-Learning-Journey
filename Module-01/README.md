# Module 01: Cyber Security Fundamentals

This module focuses on building a strong foundation in cybersecurity by covering core security concepts, common threats, attack methodologies, research fundamentals, and essential computer security principles.

## Topics Covered

- Cyber Security Fundamentals
- CIA Triad
- Cyber Threats
- Types of Attackers
- Modern Cyber Security Ecosystem
- Security Lab Setup
- Security Research Fundamentals
- AI for Cyber Security
- Operating Systems & Computer Fundamentals
- Hands-on Security Activities

## Learning Outcomes

After completing this module, I gained an understanding of:

- Fundamental cybersecurity concepts and terminology
- Confidentiality, Integrity, and Availability (CIA Triad)
- Common cyber threats and attack techniques
- Security research methodologies
- Safe lab environments for learning and testing
- The role of AI in cybersecurity
- Computer and operating system fundamentals relevant to security
