## 1. What Is Cyber Security?

Cyber Security is the practice of protecting computers, networks, applications, and data from cyberattacks, unauthorized access, damage, or theft.

### Main Goals of Cyber Security

The three main goals are known as the **CIA Triad**.

- **Confidentiality:** Only authorized people can access information.
- **Integrity:** Information remains accurate and is not changed without permission.
- **Availability:** Systems and data are accessible when needed.

### Examples

- Using strong passwords to protect accounts.
- Installing security updates to fix vulnerabilities.
- Using firewalls to filter network traffic.
- Detecting and removing malware.

## 2. Why Cyber Security Is Important

Cyber Security helps protect personal information, businesses, and digital systems from cyber threats.

### Key Reasons

- **Data Protection:** Protects sensitive information from theft or exposure.
- **Privacy:** Prevents unauthorized access to personal information.
- **Financial Security:** Helps prevent online fraud and financial losses.
- **Business Protection:** Reduces downtime and business disruption.
- **System Availability:** Helps keep services running during attacks.
- **Trust and Reputation:** Protects the reputation of individuals and organizations.
- **Legal Compliance:** Helps organizations meet applicable security and privacy requirements.

### Example

If an attacker steals a user's banking password, they may access the account and attempt unauthorized transactions. Strong authentication and security monitoring can help prevent or detect this activity.

## 3. Information Security vs Cyber Security

Information Security and Cyber Security are related, but their scopes are different.

| Information Security (InfoSec) | Cyber Security |
|---|---|
| Protects information in any form. | Focuses on protecting digital systems and environments. |
| Covers digital and physical information. | Covers computers, networks, applications, and digital data. |
| Includes physical documents and access controls. | Includes firewalls, endpoint security, and threat detection. |
| Focuses on protecting information from unauthorized access, changes, and loss. | Focuses on defending against cyber threats and attacks. |

### Example

- **Information Security:** Keeping confidential paper documents in a locked cabinet.
- **Cyber Security:** Protecting a computer from malware and unauthorized network access.

**Remember:** Cyber Security is generally considered a part of the broader field of Information Security.

## 4. Cyber Security Domains

Cyber Security has several domains, each focusing on a different area of protection.

### 4.1 Network Security

Protects computer networks from unauthorized access, attacks, and suspicious traffic.

**Examples:** Firewalls, network segmentation, and intrusion detection systems.

### 4.2 Application Security

Protects software and web applications from vulnerabilities and attacks.

**Examples:** Secure coding, input validation, and web application testing.

### 4.3 Cloud Security

Protects cloud infrastructure, services, applications, and stored data.

**Examples:** Identity and access management (IAM), secure cloud configurations, and cloud monitoring.

### 4.4 Endpoint Security

Protects devices connected to a network.

**Examples:** Laptops, desktops, servers, and mobile devices protected using endpoint security tools.

### 4.5 Identity and Access Management (IAM)

Ensures that the right people have the right access to the right resources.

**Examples:** Multi-factor authentication (MFA), role-based access control (RBAC), and least privilege.

### 4.6 Security Operations and Incident Response

Monitors systems, detects threats, investigates suspicious activities, and responds to security incidents.

**Examples:** Security Information and Event Management (SIEM), log analysis, and incident containment.

### 4.7 Governance, Risk, and Compliance (GRC)

Helps organizations manage security risks, establish policies, and meet applicable regulations and standards.

**Examples:** Risk assessments, security policies, and compliance audits.

## 5. Modern Threat Landscape

The modern threat landscape refers to the current types of cyber threats, attackers, and attack methods that individuals and organizations face.

### Common Cyber Threats

**1. Phishing**

Attackers use fake emails, messages, or websites to trick people into revealing passwords or other sensitive information.

**2. Malware**

Malicious software designed to damage systems, steal information, or perform unauthorized activities.

Examples: Viruses, worms, spyware, and trojans.

**3. Ransomware**

Malware that encrypts files or systems and demands payment to restore access or threatens to expose stolen data.

**4. Credential Theft**

Attackers steal usernames, passwords, session tokens, or other authentication information to gain unauthorized access.

**5. Social Engineering**

Attackers manipulate people into revealing information or performing unsafe actions.

**6. Denial-of-Service (DoS/DDoS)**

Attackers overwhelm a system or service with traffic or requests, making it difficult for legitimate users to access it.

**7. Insider Threats**

Security risks caused by people inside an organization, either intentionally or accidentally.

**8. Misconfiguration and Vulnerability Exploitation**

Attackers exploit security weaknesses, outdated software, or incorrectly configured systems to gain access or compromise data.

### Why Modern Threats Are Challenging

- Attack techniques continue to evolve.
- Organizations depend on cloud services and connected devices.
- Stolen credentials can allow attackers to bypass weak security controls.
- Attackers may use automation and AI to improve certain attacks.
- Third-party suppliers can introduce additional security risks.

### Basic Protection Methods

- Use strong, unique passwords and a password manager.
- Enable multi-factor authentication.
- Keep operating systems and applications updated.
- Avoid suspicious links and attachments.
- Apply least-privilege access.
- Monitor logs and investigate unusual activities.
- Maintain backups and test recovery procedures.
