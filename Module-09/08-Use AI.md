## Use AI

Use AI as a helper when reviewing cloud architecture and investigating security issues.

You can use AI for:

* Reviewing cloud architecture
* Analyzing potential threats
* Performing cloud security assessments
* Investigating security incidents
* Identifying possible security weaknesses
* Understanding cloud security risks

---

## Validate AI Output

Don't blindly trust AI-generated recommendations.

Always:

* Review the cloud security recommendations
* Verify the identified security findings
* Check whether the recommendations are correct
* Assess the risks before implementing changes
* Test and verify security improvements

> **Use AI as a helper, but always verify its recommendations before applying them to a cloud environment.**
